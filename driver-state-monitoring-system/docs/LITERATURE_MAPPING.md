# 문헌과 구현의 대응

아래 R1~R7 상세 대응은 보존된 엄격한 literature 모드에 대한 기록이다. 현재 기본 prototype 모드에 모두 활성화됐다는 뜻은 아니다. 현재 활성 범위와 미준비 항목은 [EYE_CLOSURE_STATE.md](EYE_CLOSURE_STATE.md)의 문헌 반영 범위에서 구분한다.

2026-11-11. 외부 문헌의 방법과 수치, 프로젝트 상태 연결, 구현용 품질 설정을 구분한다. 문헌의 성능을 재현하거나 Euro NCAP 평가 전체를 충족한다는 의미는 아니다.

## R1: EAR, MAR, 60초 눈 감김 비율

[Quiles-Cucarella et al., Sensors 2024](https://doi.org/10.3390/s24175683)의 2.2.2, 식(1), 식(2), 식(5), 식(6), Figure 3과 분 단위 비율 설명을 확인했다.

EAR 계산 구조를 MediaPipe의 각 눈 6개 점에 적용한다. 새 모드는 양쪽 EAR의 평균을 사용하고, 검토된 평상시 눈 뜸 표본의 평균에 0.75를 곱한다. Face Mesh로의 이식과 눈 보정 구간 분리는 적용 설계다. EAR 배율을 실제 눈꺼풀 폐쇄율로 설명하지 않는다. 히스테리시스와 임계값 제한은 구현 설정이며 요청값과 실제 적용값을 기록한다.

원문 MAR의 마지막 분자는 거리(p4,p5), 분모는 2*거리(p1,p5)다. 대칭적인 식으로 고치지 않았다. 문자 그대로 계산하는 경로는 준비했으나 MediaPipe 점 대응과 최대 입 벌림 5초의 평균값이 검토된 프로필이 없으면 경고를 활성화하지 않는다. 기존 단일 세로 거리 MAR은 관찰 로그에 남긴다.

고정된 60초 전체를 눈 감김 비율의 분모로 사용한다. 모르는 시간을 U, 확실히 감긴 시간을 C라 하면 C/60부터 (C+U)/60까지 기록한다. 범위 처리는 결측에 대한 수학적 적용 설계다. 20%와 60초 구간은 문헌 참고이며 표준 P80 측정을 주장하지 않는다.

## R2: 눈 감김 1.5초

[Kim, Jung and Choi, Sensors 2019](https://doi.org/10.3390/s19143200)의 Table 2에서 medium fatigue 조건 중 눈 감김 1.5초 이상을 확인했다. 이를 우리 CAUTION에 연결한 것은 적용 설계다. 논문의 다른 조건을 추가 OR 규칙으로 섞지 않았다.

## R3: 꾸벅임 사건 검출

[Colic, Marques and Furht, SIGMAP 2014](https://doi.org/10.5220/0005012302410247)의 출판사 링크는 접근이 제한되어 [저자 소속 대학 원문](https://faculty.eng.fau.edu/bfurht/files/2016/11/DriverDrowsinessDetection.pdf)의 Figure 4와 설명을 대조했다. 저자본의 절 번호는 II-B/II-C다.

위아래 경계, 눈을 감은 하강, 경계 전 복귀 취소, 복귀 중 눈 뜸 허용, 속도 확인 구조를 사용한다. 현재 위치는 눈 두 점의 중간 높이를 영상 높이로 나눈 값이며 측정 이식은 적용 설계다. 경계와 속도 범위의 기본 숫자를 만들지 않고 개인과 카메라별 프로필을 요구한다. 아래 경계에서 의심 경고, 복귀 후 완료 1회 기록이라는 연결 시점도 적용 설계다.

## R4: 시선 영역 모델

[Vora, Rangesh and Trivedi, 2018](https://arxiv.org/abs/1802.02690)의 7개 시선 상태와 [저자 저장소](https://github.com/arangesh/GPCycleGAN)를 확인했다. 저장소에는 RGB와 IR 절차, 데이터별 정규화와 여러 모델이 있다. 코드 라이선스는 MIT이지만 가중치별 입력과 사용 조건까지 확인한 것은 아니다.

가중치 안내 링크는 현재 도구에서 404 또는 접근 불가였다. 가중치, 클래스 순서, 전처리를 확정하지 못했으므로 모델 연결 완료로 보고하지 않는다. 현재 코드는 명시적인 7개 출력 TorchScript 계약을 받는 어댑터다. 저장소 체크포인트를 그대로 읽는 로더나 논문 모델의 재현 구현이라고 주장하지 않는다. 실제 사용 전에는 검토된 가중치의 변환과 전처리 확인이 필요하다.

메타데이터에 클래스 순서, 평균과 표준편차, 입력 크기와 영역, RGB 조건, 라이선스, 체크섬, 카메라 전방 대응을 명시해야 한다. 미연결이면 UNKNOWN이며 기존 머리와 홍채 상대 지표로 대체하지 않는다. 어댑터 테스트에는 합성 테스트용 모델만 사용했다.

## R5: 구조적 참고

[Zhang, Yang and Feng, 2021](https://doi.org/10.1049/ell2.12286)은 전달 문서의 구조적 참고 문헌이다. 이번 환경에서 원문 접근이 되지 않아 수치를 독립적으로 확인하지 못했다. 2초와 인지적 주의분산 계산식은 채택하지 않았다.

## R6: 전방 이탈 경고 시간

[Koniakowsky et al., 2025](https://doi.org/10.1016/j.trf.2024.12.008)의 출판사 초록에서 연속 이탈 3초 또는 30초 중 누적 이탈 10초인 평가 DMS를 확인했다. 보편적인 최적 시간을 입증한 연구로 설명하지 않는다. 중복 억제와 재활성화 정책은 프로젝트 구현 설계다.

## R7: 지정된 정차 요청 경로

[Euro NCAP Driver Engagement v1.2, July 2026](https://cdn.euroncap.com/cars/assets/Euro_NCAP_Protocol_Safe_Driving_Driver_Engagement_v1_2_ebce03a443.pdf)의 1.3.3부터 1.3.5, 문서 13쪽을 확인했다.

연속 눈 감김 3초는 추가 이유로 기록한다. 검증된 후보의 눈 감김 6초와 실제 주의분산 경고 후 전방 미복귀 3초만 시험용 정차 경로로 사용한다. EAR 대리 측정과 DANGER 및 Unity 정차 연결은 적용 설계다. 요청 전송과 경고 표시 확인을 구분하며 UNKNOWN은 연속 근거를 끊는다. 임상 상태나 인증 충족을 주장하지 않는다.
