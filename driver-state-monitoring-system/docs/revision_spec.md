# 운전자 비전 판단 기준 검토 및 코덱스 전달문

검토일: 2026년 11월 10일

이 문서는 업로드된 코드와 문헌을 대조한 수정 명세이다. 현재 코드는 변경하지 않았다. 앞서 전달한 스크립트와 추가 지시 대신 이 통합본을 사용한다.

## 검토 결과와 이상한 조건

눈 감김 3초만으로 경고를 시작하면 짧은 눈 감김을 놓칠 수 있다. 이번 안은 R2 Table 2의 1.5초를 초기 경고로 채택한다. R7의 1초에서 2초라는 범위에서 임의로 중간값을 만든 것이 아니다. 서로 다른 연구에서 가져온 측정과 시간 조건을 결합한 적용 설계이며, 그 조합의 성능은 우리 영상으로 확인해야 한다.

꾸벅임 삭제 지시는 취소한다. R3는 눈 상태와 고개의 하강 및 복귀를 함께 보는 구조의 근거이다. 기존 30초에 2회나 하강 비율 0.12까지 근거가 생긴 것은 아니다. 경계와 속도의 개인별 보정이 남아 있다.

평상시 EAR의 0.75배는 실제 눈꺼풀 폐쇄 75% 또는 P80과 같지 않다. 이 후보 판정을 곧바로 의식 소실이나 Euro NCAP의 무반응 판정으로 바꾸면 안 된다. 눈 감김 판정의 실제 영상 확인과 시험용 상태 연결을 구분한다.

R1의 MAR 식(1)은 마지막 분자에 p4와 p5를 쓰고, 분모에도 입 너비에 해당하는 p1과 p5를 쓴다. 점 대응 확인 없이 일반적인 대칭 세로 거리 식으로 정정하거나, 기존 단일 세로 거리 MAR에 0.35를 옮기는 것은 부정확하다. 이 부분은 원문 구현을 확인하기 전 새 경고 활성화를 보류한다.

R1의 눈 감김 비율은 60초 구간에 대한 값이다. 8초 관측에서 35%로 경고하거나 관측된 시간만을 분모로 쓰는 현재 방식과 다르다. 15초에서 30초 영상에는 장기 지표 경고를 적용하지 않는다.

R4는 새 시선 모델을 쓰는 방향의 근거이지 현재 머리와 홍채 상대 지표가 이미 해당 기능을 한다는 근거가 아니다. 카메라 정면과 도로 전방도 다를 수 있다. 미러와 계기판을 모두 AWAY로 묶는 것은 프로젝트의 단순화이며 실제 주행에서는 불필요한 경고 여부를 확인해야 한다.

CAUTION의 원인이 입 벌림에서 자세 변화로 바뀌어도 3초를 합산해 정차시키는 기존 구조는 제거 대상이다. R7의 3초는 모든 경고의 공통 정차 시간이 아니라 주의분산 경고 이후 전방 미복귀에 해당한다. 요청만 전송한 것과 실제 경고가 표시된 것도 구분한다.

가슴 부근 손과 상체 기울기의 기존 경고를 제외하면, 눈과 시선 조건에 걸리지 않는 응급상황 모사를 감지하지 못할 수 있다. 이 공백을 숨기지 말고 생체신호와 운전자 응답으로 보완할 부분으로 남긴다. 손을 가슴에 댄 것만으로 심정지를 판단하지 않는다.

검출 신뢰도, 최소 픽셀 크기, 추적 유지 시간, 히스테리시스 등은 위험 상태의 문헌 기준과 성격이 다르다. 문헌에 숫자가 없다는 이유만으로 모두 삭제하지 않는다. 목적과 테스트 결과로 설명한다.

새 규칙은 독립적인 설정 모드로 관리해줘. 기존 규칙은 재현용으로 분리하고 새 모드에 섞이지 않게 해줘.

각 기능에 준비됨, 보정 필요, 모델 미연결, 관측 불가 등의 상태를 기록해줘.
필수 기능이 비어 있는 설정으로 문헌 기반 전체 판단이 완성됐다고 표시하지 말아줘.

눈 감김 측정

R1 식(2)의 EAR 계산 구조와 현재 랜드마크를 확인해줘.
유효한 초기 평상시 눈 뜬 상태 EAR의 평균에 0.75를 곱해 눈 감김 후보 기준을 설정해줘.
기존 70번째 백분위수와 0.70 계수를 함께 변경해줘.

이 값은 EAR 기반 후보 기준이다. 75% 실제 눈꺼풀 폐쇄나 표준 PERCLOS P80을 뜻하지 않는다.
눈을 실제로 뜬 구간과 감은 구간에서 판정이 맞는지 확인해줘. 시작부터 감은 눈을 평상시 기준으로 보정하지 말아줘.
기존 임계값 제한을 적용하면 원래 0.75배와 달라질 수 있으므로 조용히 덮어쓰지 말고 설정과 실제 적용값을 로그에 남겨줘.
열림 복귀 히스테리시스와 평활화는 구현 설정으로 구분하고 경고 시간을 과도하게 늘리지 않는지 점검해줘.

눈 감김 경고와 위험

새 기본 눈 감김 CAUTION은 연속 1.5초로 설정해줘. R2 Table 2의 medium fatigue 정의를 참고한 적용 설계이다.
이전 스크립트의 ‘눈 감김 3초에 처음 경고’는 이 값으로 대체한다.

연속 3초 이상은 prolonged_eye_closure 같은 추가 판단 이유로 기록하고 경고를 유지해줘. 자동 정차의 별도 시작 조건으로 사용하지 않는다.
연속 6초 이상은 R7 1.3.5를 참고한 시험용 DANGER 조건이다. 실제 눈 감김 검출이 확인되지 않았다면 이 정차 경로를 검증 완료로 활성화하지 말아줘.
단순히 EAR이 낮았다는 이유로 실제 수면이나 무반응을 확정하는 문구는 사용하지 않는다.
눈 감김 시작부터 시간을 계산하고 다른 CAUTION의 시간을 더하지 않는다.

꾸벅임

꾸벅임은 핵심 졸음 판단 항목으로 유지한다. 보조 정보로만 남기거나 기능을 삭제하지 않는다.
R3 2.2와 Figure 4의 두 위치 경계, 하강 중 눈 감김, 하강 및 복귀 속도 관찰 구조를 참고해 별도의 사건 검출기로 정리해줘.

고개 하강 후보와 완성된 꾸벅임을 구분해줘.
하강 중 눈을 뜨거나 아래 경계에 도달하기 전에 복귀하면 해당 졸음성 꾸벅임 후보를 취소한다.
아래 경계 이후 복귀 과정에서 눈을 뜨는 것은 가능하므로, 복귀 중 눈을 떴다는 이유만으로 완성된 움직임을 모두 취소하지 않는다.
관측 실패를 고개 복귀로 계산하거나 꾸벅임 횟수에 더하지 않는다.

꾸벅임 의심 단계의 경고와 복귀 후 1회 기록을 구분해줘. 경고 시점은 우리 적용 설계로 명시하고, 미래 프레임을 사용해 경고를 과거 시점에 발생시킨 것처럼 기록하지 않는다.
이 경로에 눈 감김 1.5초 또는 3초와 ‘30초에 2회’를 추가 필수조건으로 요구하지 않는다.
꾸벅임 경고만으로 DANGER를 발생시키지 않는다.

R3는 현재 코드의 0.12, 0.25초에서 3초, 30초에 2회를 그대로 제시하지 않는다.
눈 위치를 사용한 원문과 코 및 어깨 기반 현재 지표가 같은 측정인지 확인하고, 다르면 변환과 보정을 적용 설계로 기록해줘.
카메라와 개인에 맞는 경계 및 속도 보정값을 별도 프로필로 관리해줘. 제공된 보정 자료가 있으면 계산 과정과 값을 저장해줘.
보정 자료가 없거나 재현 방법이 확정되지 않았다면 임의의 숫자를 ‘논문 기준’으로 만들지 말아줘. 기능과 사건 검출 구조는 남기고 ‘보정 필요’로 표시해줘.
기존 꾸벅임 구현은 재현용 모드에 보존하고, 새 기능이 준비되기 전에 무조건 삭제하지 말아줘.

입 벌림

R1 식(1)과 Figure 3의 입 랜드마크 대응을 먼저 확인해줘.
원문 식에는 마지막 분자 항에 p4와 p5가 들어가므로, 대칭적인 세로 거리 계산으로 임의 정정하거나 원문과 같다고 주장하지 말아줘.
현재 단일 세로 거리와 입 너비로 계산하는 MAR에 R1 기본값 0.35를 그대로 적용하지 않는다.

원문의 점 대응이 확인되면 대응되는 MediaPipe 점과 계산식을 명시하고 구현해줘.
재현이 불명확하면 현재 MAR과 로그는 유지하되 새 문헌 기반 입 벌림 경고는 준비되지 않은 것으로 표시해줘. 독립적으로 타당한 다른 계산식을 선택하려면 출처와 스케일, 보정 방식을 새로 기록해줘.

같은 측정 정의가 확인됐을 때 R1의 최대 입 벌림 5초 보정과 평균 MAR의 0.5배를 사용해줘.
평상시 눈 뜸 및 정면 보정과 최대 입 벌림 보정은 사용자 안내와 저장 구간을 구분해줘.
새로운 보정값을 확보하지 못했는데 기존 평상시 MAR에 0.5를 곱해 대체하지 않는다.

검증한 입 벌림 판정이 연속 3초 이어지면 CAUTION으로 처리해줘.
이유는 ‘지속적인 입 벌림’으로 표시하고 하품 확정으로 표시하지 않는다.
대화나 노래도 입을 벌릴 수 있으므로 일반 대화 영상에서 불필요한 경고가 발생하는지 확인해줘.
입 벌림 경고는 정차 타이머에 연결하지 않는다.

장기 눈 감김 비율

R1을 참고해 60초의 완성된 구간에서 EAR 기준 눈 감김 비율 20%를 사용해줘.
기본은 고정된 60초 구간으로 계산하고, 이동 창으로 바꾸면 원문 그대로가 아니라 적용 설계임을 표시해줘.
기존 8초 관측 후 35% 경고와 65% 관측 비율을 새 문헌의 값처럼 유지하지 않는다.

관측 누락을 눈 뜸으로 채우거나 유효 관측 시간으로 분모를 바꾼 값을 원문의 60초 비율과 동일하게 설명하지 않는다.
누락이 있을 때는 확실한 눈 감김 시간 C와 모르는 시간 U를 기록하고, 실제 비율의 가능한 범위를 C/60부터 (C+U)/60으로 계산하는 방식으로 보수적으로 처리할 수 있다.
이 범위 처리는 문헌 수치가 아니라 결측 처리에 대한 수학적 구현 설계이다.
하한이 0.20 이상이면 높은 비율로 판단할 수 있고, 상한이 0.20 미만이면 해당 기준에는 미달하며, 범위가 기준을 걸치면 비율 판단을 보류해줘.

60초가 쌓이기 전에는 해당 항목만 COLLECTING으로 표시해줘.
서로 다른 짧은 파일을 자동 연결해서 60초를 만들지 않는다.
비율 경고는 장기 CAUTION 또는 휴식 안내로 처리하고 정차용 무반응 시간에 더하지 않는다.
고정 구간 결과를 언제까지 유지할지와 경고 해제 및 중복 알림 정책을 별도로 문서화해줘. 오래된 결과를 영구적으로 계속 쓰지 않는다.

전방 주시 추정

R4의 시선 영역 추정 방법을 참고해 별도 모듈을 연결해줘.
저자 저장소의 실제 가중치, RGB 또는 IR 입력, 전처리, 클래스 순서와 라이선스를 확인한 뒤 사용해줘.
공개 코드가 있다는 이유만으로 검증된 모델이 이미 연결됐다고 가정하지 않는다.
모델 다운로드에 사용자 계정이나 별도 허가가 필요하면 그 부분을 알리고, 가능한 나머지 작업은 진행해줘.

전방을 FORWARD, 전방 외 시선 영역을 AWAY로 묶는 것은 우리 프로젝트의 단순화이다.
원래 시선 영역도 함께 보존해 미러나 계기판 확인과 다른 행동을 구분해 기록해줘.
카메라 정면을 보는 것과 실제 도로 전방을 보는 것이 일치하는지 설치 위치와 초기 시선을 확인해줘.

눈 감김과 신뢰할 수 없는 추정은 별도 처리한다. 모델의 eyes_closed 클래스를 정상 또는 AWAY로 억지 변환하지 않는다.
기존 yaw 14, pitch 12와 홍채 및 어깨 상대 지표를 정밀한 시선 모델의 결과처럼 표시하지 않는다.
모델이 준비되지 않았으면 UNKNOWN으로 표시해줘. 기존 방식은 재현용 상대 지표 모드로 보존할 수 있으나 새 문헌 기반 모드에 조용히 섞지 않는다.

전방 이탈 경고

R6을 참고해 연속 AWAY 3초 또는 최근 30초 중 AWAY 누적 10초를 CAUTION 조건으로 사용해줘.
기존 10초 중 3회, 10초 중 4초 등의 경고와 이에 붙은 현재 이탈 0.5초 조건은 새 모드에서 제거해줘.
관측하지 못한 시간과 눈 감김 시간을 AWAY로 채우지 않는다.
원래 시선 영역과 경고 이유를 로그에 남겨줘.
과거 누적 이력만으로 정상 복귀 후 매 프레임 새 경고를 발생시키지 않도록 중복 억제와 재활성화 정책을 명시하고 테스트해줘. 해당 정책은 별도 구현 설계로 구분해줘.

주의분산 경고 후 위험

R7 1.3.5를 참고한다.
실제로 주의분산 경고를 표시하거나 실행한 시점을 warning_issued_at으로 기록해줘.
화면에서 시각 경고를 표시하는 경우와 Unity로 요청만 보낸 경우를 구분하고, 요청만으로 실제 경고 실행을 확인했다고 주장하지 않는다.

경고 후 3초 동안 계속 AWAY인 것이 관측되면 DANGER로 정차를 요청해줘.
FORWARD가 확인되면 이 경로의 연속 시간을 초기화한다.
UNKNOWN이나 눈 감김으로 시선을 확인하지 못하면 계속 AWAY라고 가정하지 않는다.
다른 CAUTION 이유로 바뀌어도 같은 무응답 시간이 이어지는 구조로 구현하지 않는다.
이 규칙은 경고 후 전방 미복귀에 따른 시험용 대응이지 버튼 무응답의 확인이나 의식 상태 진단이 아니다.

기존 조건 정리와 응급상황

기존 눈 감김과 이상 자세 각각 0.4초, 긴 감김 3회, 머리 방향 2초, 상체 20도 또는 34도, 머리 내려감 고정값, 가슴 부근 손 1초 등의 독립 경고는 새 모드에서 문헌 확정 규칙으로 사용하지 않는다.
각 특징의 검출과 로그는 유지하고, 이 조치를 꾸벅임 기능 삭제로 해석하지 않는다.

손이 가슴에 가깝다는 정보만으로 통증, 심정지, 의식 소실을 판단하지 않는다.
휴대전화, 음식, 음료 용기, 식기, 책과 핸들 부근 손 위치는 보조 정보로 유지한다.
이 조정으로 눈과 시선 조건에 해당하지 않는 E 시나리오를 감지하지 못할 수 있음을 명시해줘.
그 공백을 메우려고 임의의 응급 경고 규칙을 추가하지 말고, 생체신호나 별도 운전자 응답과 연결해야 할 입력을 정리해줘.

최종 상태와 정상 복귀

NORMAL은 활성화된 필수 관측 항목이 유효하고 경고 조건과 미해소 원인이 없는 상태이다.
CAUTION은 검증 가능한 경고 조건 또는 문서화한 장기 경고가 활성화된 상태이다.
DANGER는 위에서 정한 두 정차 경로에 한정한다.
경고 근거가 없고 필요한 관측이 부족하면 UNAVAILABLE로 처리한다.
일부 정보가 없더라도 다른 유효한 정보에서 확인된 경고를 무조건 제거하지 않는다.
60초 비율의 COLLECTING이나 선택 기능의 미준비를 전체 관측 실패와 동일하게 취급하지 않는다. 필수 기능 미준비는 별도 표시한다.

순간 행동 경고는 원인 해소를 확인해 복귀하고, 장기 비율 경고는 별도의 구간 결과와 해제 정책을 적용해줘.
기존 정상 복귀 안정화 0.3초, 영상 간격 검사 등의 값은 구현 설정으로 관리하고 문헌의 생리학적 기준처럼 설명하지 않는다.
복귀 대기 시간만으로 정차가 발생하지 않게 해줘.

기본 sustained_caution 정책과 모든 CAUTION을 합산하는 3초 타이머를 새 모드에서 제거해줘.
기존 외부 경고 5초와 별도 응답 입력을 이용하는 선택 기능은 비활성 상태로 분리해줘.
관측 실패를 외부 무응답으로 바꾸지 않는다.

시간과 누락

영상 분석은 영상 타임스탬프를 기준으로 시간을 계산하고, 라이브 입력은 일관된 단조 시계를 사용해줘.
재생 일시정지나 처리 지연 시간을 행동 시간으로 더하지 않는다.
필터링된 오래된 값이나 물체 추적 유지값을 현재 눈 또는 시선 관측처럼 사용하지 않는다.
UNKNOWN 구간은 연속 이상 행동의 관측 근거를 끊고, 누적 조건에서는 모르는 시간으로 분리해줘.
정상 복귀로 바뀐 것과 관측이 끊긴 것을 로그에서 구분한다.
새 영상, 시간 역행, 세션 변경 시 이전 사람과 파일의 타이머가 이어지지 않게 해줘.

Unity와 화면

기존 통신 형식을 확인하고 상태, 판단 이유, 행동 지속 시간, 경고 발행 시점, 각 기능의 관측 및 준비 상태를 일치시켜 전달해줘.
이미 시작한 정차를 NORMAL이나 UNAVAILABLE 패킷만으로 취소하지 않는다.
현재 관측 상태와 Unity의 정차 진행 및 해제 상태를 분리해줘. 해제는 명시적인 운전자 응답이나 정해진 시뮬레이터 제어 정책으로 관리해줘.
오래된 판단 결과는 정상으로 계속 재사용하지 말고 기존 신선도 검사를 유지해줘.

화면의 타이머 분모와 판단 설명도 새 설정에서 읽게 해줘.
하품 확정, 심정지 감지, 의식 소실 확정, Euro NCAP 인증 또는 기준 충족 같은 표현은 사용하지 않는다.
현재 정보로 확인할 수 없는 행동은 모름으로 표시해줘.

보존할 구현 설정

검출 신뢰도, 최소 얼굴 크기와 눈 사이 거리, 밝기와 가림 검사, 표본 수, 물체 추적 유지 시간, 필터와 히스테리시스 등은 행동 위험 기준과 구분한다.
논문에 숫자가 없다는 이유만으로 모두 삭제하지 말고 목적과 실제 영향을 점검해줘.
현재 머리 방향 값이 실제 각도가 아닌 상대 지표라면 변수명과 화면 단위를 바로잡아줘.
rPPG의 계산과 저장은 유지하고 상태 판단 입력에는 넣지 않는다.

검증

시간 경계 직전과 직후, 프레임 간격 변화, 관측 누락, 원인 변경, 정상 복귀, 영상 전환을 테스트해줘.
눈 경고 1.5초, 추가 이유 3초, 정차 조건 6초, 연속 전방 이탈 3초, 누적 30초 중 10초, 실제 주의분산 경고 후 3초를 확인해줘.
UNKNOWN이 정차 타이머에 더해지지 않는지, 입 벌림과 장기 비율 경고가 정차로 합산되지 않는지 확인해줘.
꾸벅임은 정상 고개 움직임, 눈 뜬 채 아래 보기, 하강 중 관측 누락, 눈 감김을 동반한 하강 및 복귀를 구분해 확인해줘.
입 벌림은 일반 대화와 큰 입 벌림을, 전방 주시는 짧은 미러 확인과 지속적인 다른 곳 보기를 확인해줘.
60초 비율은 짧은 영상의 수집 중 표시와 결측 시간 범위 계산을 확인해줘.
정차 요청 후 관측 실패나 NORMAL이 도착해도 정차가 의도치 않게 취소되지 않는지 확인해줘.

제공된 실제 영상이 있으면 전환 시점과 판단 이유를 확인하고, 없으면 실행 가능한 단위 테스트와 자료가 필요한 검증을 구분해줘.
한 사람의 연기 영상에 맞춘 보정 결과를 일반화 정확도나 실제 졸음 진단 성능으로 보고하지 않는다.

작업 결과

변경 파일과 실행 방법, 실제 기본 설정, 문헌별 사용 위치와 원문 절, 우리 적용 설계, 구현 설정을 정리해줘.
구현과 검증이 끝난 기능, 코드만 준비된 기능, 보정 또는 가중치가 필요한 기능을 구분해줘.
문헌상 수치가 있더라도 우리 측정 방식과 대응이 확인되지 않으면 그 점을 명시해줘.
작업 가능한 부분은 끝까지 진행하고, 근거와 자료가 없는 부분을 임의로 완성했다고 보고하지 말아줘.
