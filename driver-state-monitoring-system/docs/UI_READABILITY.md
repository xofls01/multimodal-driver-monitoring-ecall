# 화면 표시 정리

내부 상태 코드 대신 현재 관측 결과, 경고 기준, 아직 필요한 준비를 한국어로 구분한다. 판단 기준과 모델, 보정 프로필은 변경하지 않았다.

현재 결과: [영상 모음](../outputs/revision_readable_ui/index.html)

눈 상태 아래에는 연속 눈 감김 시간과 설정 파일의 주의 기준을 표시한다. 시간은 소수 둘째 자리까지 표시해 기준에 도달하지 않았는데 반올림으로 도달한 것처럼 보이는 상황을 줄였다.

전방 주시 모델이 미연결이거나 측정할 수 없으면 확인 불가로 표시한다. 이때 연속 이탈 시간과 누적 이탈 시간은 0초 대신 --로 표시한다. 시선 모델 연결이 필요하다는 안내도 함께 표시한다.

꾸벅임과 입 벌림은 보정이 필요하면 그대로 안내한다. 보정이 없는데 꾸벅임 0회라고 표시하지 않는다. 손과 가슴의 근접, 물체 후보는 별도 보조 관찰로 표시한다.

눈 감김 비율의 수집 시간은 60초 구간에서 경과한 시간이다. 해당 시간 전체에서 눈을 읽었다는 뜻은 아니다. 구간 완료 후에는 관측 불가 시간을 포함한 비율 범위를 표시한다. 영상 맥박 추정은 정상 시나리오의 별도 실험이며 상태 판단에 사용하지 않는다.

기존 장면과 랜드마크 표시는 유지하고 오른쪽 패널만 교체했다. 새 영상은 D2 496프레임, E4 469프레임, N1 479프레임이며 모두 1700 x 720이다. 원본 장면 1280 x 720의 위아래를 자르지 않았다. 기존 결과를 다시 인코딩했으므로 압축에 따른 미세한 화질 차이는 생길 수 있다.

## 파일

- src/driver_state_tools/readable_dashboard.py: 화면 문구와 패널 렌더링
- src/driver_state_tools/dashboard.py: 문헌 모드의 새 패널 연결
- scripts/rerender_readable_review.py: 저장된 실제 관측 기록으로 패널만 다시 생성
- tests/test_readable_dashboard.py: 미관측, 기준값, 입력 보존과 한국어 폰트 대체 표시 확인

## 다시 만들기

프로젝트 폴더에서 준비된 Python 환경으로 실행한다. 출력은 기존 폴더를 덮어쓰지 않도록 새 경로를 지정한다.

```bash
python scripts/rerender_readable_review.py \
  --run outputs/revision_actual \
  --output outputs/readable_review_new
```

새 영상 분석은 기존 run.sh 명령으로 실행하면 새 패널을 사용한다. 기존 기록의 재생성은 모델 추론과 판단을 다시 실행하지 않으며 Unity로 상태를 전송하지 않는다. 원래 기록에 있는 각 시점의 판단을 그대로 사용한다. 오래된 결과 재생을 현재 판단의 실시간 전송으로 간주하면 안 된다.

이 컴퓨터에서는 AppleGothic 시스템 폰트를 사용한다. 폰트 파일을 저장소에 복사하지 않는다. Windows에서는 맑은 고딕, Linux에서는 Noto Sans CJK 또는 나눔고딕 경로를 자동 확인한다. config/vision_baseline.json의 ui_font_path로 한글 폰트를 지정할 수도 있다. 한글 폰트가 없으면 읽을 수 있는 영어 문구로 표시한다. ui_language를 en으로 지정해 영어를 선택할 수도 있다.

## 기능 준비 상태

시선 가중치 미연결, 꾸벅임 보정 필요, 입 벌림 점 대응과 보정 필요 상태를 유지했다. D2 눈 감김 검증 실패와 정차 조건 비활성도 그대로다. 이 변경은 정확도 향상이나 전체 구현 완료를 뜻하지 않는다.

기존 전체 테스트 144개와 마지막 문구 보완 후 화면 테스트 11개를 통과했다. 영상별 프레임 수, FPS, 해상도, 기존 입력의 해시를 확인했다. 장면 픽셀은 인코딩 전 동일함을 확인했다. 실제 Unity Editor와 차량 정차 동작은 실행하지 않았다.
