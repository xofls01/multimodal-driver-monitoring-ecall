# 판단 경로 복구와 시각화

후속 변경: 경고 기준 전 유효한 눈 감김을 Normal의 평가 중 상태로 처리했다. 아래 실제 실행 수치는 이전 실행 기록이며, 현재 상태 처리와 재평가 결과는 [EYE_CLOSURE_STATE.md](EYE_CLOSURE_STATE.md)에 있다.

## 왜 이전보다 둔감해 보였는가

모델 가중치를 바꾼 결과가 아니다. 문헌 모드가 시선 영역 모델을 필수 입력으로 요구했지만 가중치는 연결되지 않았고, 검토된 눈 보정이 없는 영상은 눈 상태도 미준비로 처리했다. 동시에 기존 상체와 가슴 부근 손의 독립 경고를 제외했다. 그 결과 N1도 Normal에 도달하지 못했고, E4 전체가 Unavailable이었다.

이전 통합 명세는 근거가 없는 기존 자세 경고를 문헌 확정값으로 사용하지 않도록 요구했다. 그 제한을 유지하는 문헌 모드와 실제 시연용 판단을 분리하지 않고, 기능이 개선된 최종 시스템처럼 제시한 점이 문제였다.

엄격한 문헌 모드의 엔진과 설정은 보존했다. 이번 요청에 따라 기존 관찰 특징을 사용하는 prototype 모드를 추가했다. 추가 경고와 자세 정차 기준은 시험용 설정이며 문헌의 검증 결과로 설명하지 않는다. 모든 Caution을 합산하는 3초 정차 타이머는 복구하지 않았다.

## 관측과 보정

YOLO26n Pose와 Detection, MediaPipe Face Mesh와 Hands를 유지했다. 시나리오 ID로 상태를 결정하거나 20개 학습 클래스로 학습하지 않았다. 시나리오 이름은 파일 정리와 정상 시나리오의 별도 rPPG 실험 선택에만 사용한다.

소스 해시에 연결한 중립 구간을 검토했다. N1은 0~0.6초, D2는 0.73~1.2초, D3는 0.73~1.25초, A4와 E4는 0~0.8초다. 구간이 실제로 분석될 때 유효 표본을 수집하고 구간 종료 후에만 기준을 적용한다. 최소 8개 표본이 필요하다. 미래 프레임으로 과거 경고를 발생시키지 않는다. 파일마다 상태와 타이머를 초기화한다.

D3는 처음 0~0.8초 구간에서 눈 표본이 하나뿐이었다. 검토된 눈 뜸 구간 안에서 8개를 확보하도록 보정 구간을 옮기고 해당 영상만 다시 실행했다. 눈 감김 경고 임계값은 바꾸지 않았다.

눈 EAR은 양쪽 평균을 사용하고 중립 평균의 0.75배를 후보 임계값으로 사용한다. 기존 제한 0.12~0.28과 복귀 히스테리시스 0.025는 구현 설정이다. 논문의 눈꺼풀 폐쇄율이나 표준 P80과 동일하지 않다. 실제 눈 감김을 놓치는 문제가 남아 있다. 검증되지 않은 눈 감김만의 6초 정차 경로는 비활성으로 유지했다.

## 판단 기준

눈 감김이 유효하게 1.5초 이어지면 Caution이다. 시간은 R2의 참고값이며 MediaPipe에 적용한 조합의 정확도가 검증됐다는 뜻은 아니다.

전방 이탈은 현재 연결된 머리 방향, 홍채 상대 위치와 자세의 상대 지표를 사용한다. R4의 시선 영역 CNN 결과라고 설명하지 않는다. 화면에 HEAD + IRIS PROXY 또는 POSE PROXY처럼 출처를 표시한다. 눈 감김과 미관측은 전방 이탈로 채우지 않는다.

연속 이탈 3초 또는 최근 30초 누적 10초는 R6의 시간 참고값이다. 상대 지표에 연결한 것은 적용 설계다. 추가로 0.35초 이상 이탈을 한 사건으로 세고 최근 30초에 3회 이상이면, 현재 이탈도 0.5초 이상일 때 Caution이다. 이 반복 규칙은 prototype 설정이다. 전방 복귀 후 과거 이력만으로 경고를 계속 발생시키지 않는다.

기존 머리 임계값 14와 12, 홍채 상대 변화 0.18과 0.20, 어깨 기준 머리 위치 변화 0.22, 머리 내려감 0.12는 상대 지표의 구현 설정이다. head_yaw_degrees와 head_pitch_degrees라는 기존 키 이름이 남아 있지만 실제 3차원 각도를 뜻하지 않는다.

상체가 기준보다 20도 기울어 2초 지속되면 Caution이다. 상체의 영상상 기울기 34도 또는 어깨 너비로 정규화한 머리 내려감 변화 0.20을 큰 자세 변화 후보로 사용한다. 그 자세가 0.8초 이어지면 Caution이고, 그 뒤 같은 자세가 유효하게 3초 더 이어지면 Danger로 시뮬레이터 정차를 요청한다. 따라서 가장 빠른 정차 요청은 행동 시작 약 3.8초 뒤다. 이 수치와 연결은 프로젝트의 prototype 규칙이며 심정지나 의식 소실 기준, Euro NCAP 충족으로 설명하지 않는다.

골반이 안 보여도 코와 어깨가 유효하면 머리 내려감을 판단할 수 있다. 큰 자세 변화가 관측되면 눈이나 얼굴 미관측이 그 경고를 지우지 않는다. 반대로 머리와 상체 일부가 안 보일 때, 남아 있는 한 항목이 정상이라는 이유로 큰 자세 변화가 해소됐다고 채우지 않는다. 모든 관련 관측이 없으면 새 정차 타이머를 진행하지 않는다.

가슴 근처에 손이 1초 지속되면 Caution이다. 통증이나 가슴을 움켜쥔 힘을 확인하는 기능은 아니다. 손이 안 잡혔다고 버튼 무응답이나 의식 소실로 처리하지 않는다. 이 경고는 자세 정차 시간에 더하지 않는다.

입 벌림은 현재 단일 세로 거리 MAR을 사용한다. max(0.28, 중립 MAR + 0.16) 이상이 3초 지속되면 Caution이다. R1의 입 벌림 식과 같은 측정으로 주장하지 않으며, 하품을 확정하지 않는다. 문헌 모드의 점 대응 검증 필요 상태도 그대로 보존했다. 입 벌림은 Danger로 합산하지 않는다.

꾸벅임은 삭제하지 않았다. 보정이 필요한 R3 사건 검출기와 기존 재현 경로를 보존했다. prototype에서는 눈 감김과 상대 머리 내려감 0.12가 함께 0.4초 유지되면 NOD PROXY 경고를 낸다. 기존 고개 하강과 복귀의 횟수는 HEAD DIPS로 기록한다. 최근 30초의 하강 복귀가 2회 이상이고 현재도 눈 감김을 동반한 내려감 후보가 있으면 반복 경고를 기록한다. 이것은 R3를 완전히 재현하거나 모든 고개 숙임을 졸음으로 확정하는 기능이 아니다.

0.5초 이상 2초 미만의 긴 눈 감김이 최근 30초에 3회 이상이고, 현재도 눈 감김이 0.5초 이어지면 반복 경고를 기록한다. 구체적인 시간과 횟수는 prototype 설정이다.

60초 눈 감김 비율은 완성된 고정 구간만 사용한다. 20%를 참고하고 결측 시간에 따른 비율 범위를 계산한다. 15초 영상들을 합치거나 8초 관측으로 60초 지표를 대체하지 않는다. 비율 경고는 Caution이며 자세 정차 시간에 더하지 않는다.

## 최종 상태

Normal은 중립 기준이 확보되고 얼굴과 눈, 상대 전방 주시를 읽을 수 있으며 현재 경고와 미해소 원인이 없는 상태다. 미연결 시선 CNN을 필수로 기다리지는 않지만, 상대 지표의 한계는 별도로 표시한다.

Caution은 위 경고의 지속 또는 반복 조건에 도달한 상태다. 관측 가능한 큰 자세 변화는 얼굴이 사라져도 Caution을 발생시킬 수 있다.

Danger는 이번 prototype에서 같은 큰 자세 변화가 경고 이후 3초 더 유효하게 관측됐을 때의 시험용 정차 요청이다. 가슴 손, 입 벌림, 복귀 확인 대기, 눈 감김 비율의 시간을 더하지 않는다. 눈 감김만의 미검증 정차 경로는 활성화하지 않았다.

Unavailable은 필요한 관측이 부족하거나 이전 경고 원인의 해소를 확인하지 못한 상태다. 정상으로 채우지 않는다. 다만 다른 유효한 이상 행동에서 Caution이나 Danger의 근거가 있으면 그 결과를 우선한다.

관측 간격이 0.25초를 넘거나 해당 항목이 Unknown이면 연속 근거를 끊는다. 원인 해소가 관측되면 0.3초 안정화 후 Normal로 복귀한다. 이 대기 시간으로 정차가 발생하지 않는다.

## UI

영어로 표시하고 영상 바깥에 8픽셀 상태 테두리를 추가했다. Normal은 초록색, Caution은 노란색, Danger는 빨간색, Unavailable은 회색이다. 얼굴 위에 상태 카드나 막대를 덮지 않는다.

눈 감김, 연속 전방 이탈, 최근 30초 누적 이탈, 자세 경고와 같은 자세의 정차 타이머를 현재값 / 설정값과 막대로 표시한다. 반복 이탈은 최근 사건 개수와 점 세 개로 보여준다. 고개 하강 복귀와 긴 눈 감김의 반복 횟수도 별도로 표시한다. 보조 관측에는 입 벌림, 가슴 부근 손, 상체 기울기의 시간과 기준을 표시한다. 미관측은 NOT OBSERVED로 표시한다.

서로 다른 색으로 얼굴, 눈, 자세와 손을 구분한다. rPPG는 정상 시나리오에서 이마와 볼의 별도 실험을 유지하며 상태 판단에 사용하지 않는다.

원본 장면은 1280 x 720, 패널은 460픽셀이다. 바깥 테두리를 포함한 출력은 1756 x 736이며 원본 장면의 위아래를 자르지 않았다. 원본 FPS와 프레임 수를 유지했다. 브라우저용 H.264 영상은 재인코딩에 따른 미세한 화질 차이가 있을 수 있다.

## 실행

```bash
sh run.sh --input data/source_videos/E/E4.mp4 --output outputs/new_e4 --unity
```

run.sh는 이제 prototype 설정을 기본으로 넣는다. --config와 --rules를 명시하면 지정한 모드를 사용한다. 현재 Python 실행 파일은 원본 프로젝트의 .venv/bin/python을 읽을 수 있다. 새 PC는 requirements-lock.txt로 준비한다.

```bash
python scripts/run_vision_baseline.py --input data/source_videos/E/E4.mp4 \
  --config config/prototype/vision_baseline.json --rules config/prototype/decision_rules.json \
  --output outputs/new_e4 --unity
```

아직 중립 프로필이 없는 새 영상은 처음 3초 안에서 사용자가 검토한 중립 구간을 --neutral-window START END로 지정한다. 눈을 감고 시작했거나 정상 기준을 확보할 수 없으면 그 부분을 정상으로 가정하지 않는다. 기존 해시와 다른 영상을 준비된 프로필에 억지로 연결하지 않는다.

저장된 현재 관측 기록의 판단 재검사는 scripts/verify_prototype_replay.py --run outputs/prototype_evidence_final로 수행한다. 새 추론이나 현재 Unity 전송과 구분한다. scripts/build_prototype_review.py는 판단을 바꾸지 않고 최종 영어 패널과 영상 모음을 만든다.

## 실제 확인 결과

최종 영상은 N1, D2, D3, A4, E4다. 전체 자료의 일반화 정확도를 측정한 결과가 아니다.

- N1: Normal 205개, Caution 0개, Danger 0개, Unavailable 35개
- D2: Normal 147개, Caution 21개, Danger 0개, Unavailable 80개
- D3: Normal 127개, Caution 85개, Danger 0개, Unavailable 61개
- A4: Normal 38개, Caution 115개, Danger 0개, Unavailable 74개
- E4: Normal 58개, Caution 89개, Danger 72개, Unavailable 16개

위 수는 모델 분석 시점의 개수이며 영상 프레임 전체 수와 다르다. 현재 판단 1223개가 실제 분석 함수에서 UnityStateServer.publish()에 전달됐다. TCP 모의 수신기에서 Normal, Caution, Danger와 관측 불가 및 오래된 결과의 구분을 확인했다. D3는 중립 표본 부족을 해결한 별도 재실행 기록을 선택했고, 각 실행의 수신 기록과 선택한 클립을 verification.json에 남겼다.

E4의 첫 Caution은 약 5.00초, 첫 Danger는 약 11.01초다. Caution 전체 시간의 합이 아니라 큰 자세 변화 경고 이후 같은 자세가 이어진 시간으로 정차 요청이 발생한다.

전체 자동 테스트 160개를 통과했다. 최종 결측 마스크 보완 뒤 저장된 실제 관측 1223개를 다시 입력해 상태, 이유와 지속 시간이 기존 실제 실행 결과와 일치함을 확인했다. 소스 장면의 픽셀은 인코딩 전에 유지됨을 확인했고 출력의 프레임 수, FPS, 해상도를 검사했다.

Unity Editor를 직접 실행하지 않았다. C# 컴파일, 씬 참조, 실제 차량 조향과 감속, 갓길 정차와 e-Call까지 검증했다고 보고하지 않는다. 기존 Unity 정차 유지 정책을 보존했으며 새 Normal이나 Unavailable 패킷만으로 이미 시작한 정차를 취소하지 않는다.

## 남은 검증

눈 감김을 놓치는 구간, 자세와 고개 움직임의 오경고, N5의 정상 회전 기울기와 지속 숙임의 구분, 다른 사람과 카메라 설치 조건을 추가로 확인해야 한다. 물체 후보의 오검출도 남아 있으며 물체만으로 경고를 결정하지 않는다.

선글라스 등으로 눈을 읽지 못해도 유효한 자세 경고는 가능하다. 하지만 보이지 않는 눈을 정상이라고 추정하지는 않는다. 실제 의식 상태, 심정지, 통증과 버튼 무응답은 영상만으로 확정하지 않는다. 생체신호와 별도 응답 입력은 후속 단계다.
