# Model weights

현재 실행에 사용한 사전학습 가중치 `yolo26n.pt`와 `yolo26n-pose.pt`를 함께 포함한다.
두 파일 합계는 약 13.4 MB이며, `manifest.json`에 SHA-256을 기록했다. 실행 도구가 누락·변조를 확인한다.

YOLO detect는 휴대전화 후보, pose는 신체 키포인트를 추출한다. 프로젝트 영상으로 추가 학습하지 않았으며 졸음·의식·심정지 분류 모델이 아니다.
얼굴·눈·입·손은 고정한 MediaPipe 패키지에 들어 있는 모델을 사용한다. 별도 `.task` 파일은 필요하지 않다.

새 학습 가중치는 기본적으로 Git에서 제외하며, 현재 사용한 위 두 파일만 업로드를 허용한다.
